# FloSpatial Fire Service MVP with Hydraulic Fundamentals V1

## Run locally

1. Open this folder in Command Prompt.
2. Run:

```text
npm install
npm run dev
```

3. Open the local address  shown in the terminal, usually:

```text
http://localhost:5173/
```

The testing password is:

```text
flospatial
```

## Notes

This build includes the Fire Service MVP shell plus the first Hydraulic Fundamentals learning module. Progress is saved locally in the browser.

If npm tries to download from an incorrect registry, run:

```text
npm config set registry https://registry.npmjs.org/
```

Then run `npm install` again.
